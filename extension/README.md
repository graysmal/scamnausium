# scamnasium browser extension

Right-click selected text (or a link) on any page → **Check with scamnasium**. It opens the app's Customer tab with the text pre-filled and checked in the browser. Nothing is reported until you press **Report to protect others**.

Install (Chrome / Edge / Brave):
1. Go to `chrome://extensions` and turn on **Developer mode**.
2. Click **Load unpacked** and pick this `extension/` folder.
3. Optional: click the extension icon to change the app address (default `http://localhost:5173/`).

The extension makes no network requests itself and reads only the text you right-click.
