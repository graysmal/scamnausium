## Architecture in one breath
- `spacetimedb/src/domain.ts`: pure analyzer + sanitizer + state machine, shared by module (authoritative) and gateway/frontend. `spacetimedb/src/email.ts`: raw .eml → compact `From/Reply-To/Subject/Auth:` + text body (pure, linear-time on hostile HTML).
- `spacetimedb/src/index.ts`: tables + reducers. Only the gateway identity (operator) can write.
- `services/gateway/src/`: Express on 127.0.0.1:4000. Operator Bearer secret, `/api/report`, `/api/action` (inject|protect|dismiss|decoys|reset), HMAC ElevenLabs webhook, opt-in ElevenLabs/Photon pollers, auto-reconnect to DB.
- `src/`: React + Cytoscape UI. Tabs: Network (rail | graph | inspector), Customer (in-browser check, nothing sent unless reported), Collector (mock decoys), Setup. Hash routes `#view/i|c|x/<id>`; `?check=<text>` prefill (read once at module load because StrictMode double-runs initializers).
- `extension/`: MV3 right-click "Check with scamnasium" → opens app with `?check=`.

## Decisions that look odd but are deliberate
- Stored `incidents.summary` = full sanitized message incl. header lines (capped 600). Re-analysis needs the From display name/Auth line; `parseMessage` splits body for display.
- `linkIncident` is a **no-op** when there's no scam pattern, and the ingestor always calls it. The module decides linking. Earlier the gateway decided with its own analyzer copy, so a stale gateway silently skipped links. Don't move the decision back to the gateway.
- Provider IDs stored only as `el-|ph-|rp-` + sha256[0:32]; reports deduped by hash of normalized text.
- Risk is low/medium/high by summed rule weights; no percentages anywhere (honesty rule in AGENTS.md).
- Graph "live call" node uses the future incident id so it morphs into the filed report.
- Dismissed (`Not a scam`) incidents stay in tables/feed but are filtered out of the graph; an emptied campaign is deleted.
